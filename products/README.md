# Product categories

AIARIS works in the following **category-level** product areas:

1. **Access-control edge devices** — door / portal class nodes that interact with readers, inputs, and outputs close to the physical boundary.
2. **Gateway / hub class devices** — aggregation, policy distribution, and uplink points that coordinate fleets of edge nodes.
3. **Credential and reader interfaces** — paths that accept credentials from common reader technologies and present them to local decision logic.
4. **Security automation** — software and operational layers that help operators supervise, configure, and maintain systems without depending on fragile manual procedures.

## Release boundary

Detailed product specifications, model codes, electrical designs, and firmware remain **private** until formal public release. This repository describes categories and principles only.

Do not treat the absence of a public SKU list as an invitation to infer unreleased identifiers from other sources.
