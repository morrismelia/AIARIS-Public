# AIARIS public website

Marketing site source (Hostinger Horizons export, revised for Advanced Infrastructure Operating System positioning).

## Develop

```bash
cd website
npm install
npm run dev
```

## Build

```bash
cd website
npm run build
```

Output: `website/dist/apps/web`
