# Contributing

Thank you for your interest in AIOS SYSTEMS’ public engineering notes.

## Scope of this repository

This repository accepts improvements to **public-safe documentation only**: clarity, typography, broken links, glossary definitions, and principle-level technical writing that respects [PUBLIC_DISCLOSURE_POLICY.md](PUBLIC_DISCLOSURE_POLICY.md).

It does **not** accept:

- private product source, schematics, firmware, or BOMs
- customer or site information
- credentials, tokens, or internal infrastructure details
- speculative vulnerability write-ups intended for public filing (see [SECURITY.md](SECURITY.md))

## How to propose a documentation change

1. Open a GitHub issue describing the clarification you want (preferred for non-trivial edits).
2. Or open a pull request that changes only markdown under this repository.
3. Keep tone professional and English-first.
4. Do not paste content from private AIOS repositories or employer-confidential sources.

## Review

Maintainers may edit, reject, or rewrite submissions to preserve disclosure boundaries and technical accuracy. There is no SLA for community review time.

## Code of conduct (short)

Be respectful. Do not harass maintainers or third parties. Do not use this repository to solicit customers with confidential site details.
