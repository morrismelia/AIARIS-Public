# Glossary

| Term | Meaning in this repository |
|---|---|
| Edge node | Device near a portal that handles local I/O and often local authorization |
| Gateway / hub | Aggregator that coordinates nodes and uplink without replacing local enforcement |
| Edge-first | Preference for local decisions when policy and safety allow |
| Eventual synchronization | Catch-up of state/events after connectivity returns |
| Policy | Rules governing authorization and related behaviors |
| Credential | Secret or tokenized proof presented at a reader |
| RS-485 | Common differential industrial multi-drop physical layer (conceptual discussion only here) |
| DFM / DFT | Design for manufacturing / design for test |
| RED / AMBER / GREEN | Disclosure classes defined in the public disclosure policy |

This glossary is descriptive for public notes. It is not a standards-body definition set.
