# Security

## Reporting a vulnerability

Do **not** open a public GitHub issue that includes exploit details, credentials, firmware dumps, or site-specific attack paths.

Until a dedicated public security mailbox is formally published, contact the repository maintainers **privately** through available GitHub account / maintainer contact mechanisms associated with `morrismelia`.

Please include:

- a clear description of the affected product category or public document
- steps to reproduce at a high level (without enabling mass exploitation)
- your contact method for follow-up
- whether you believe the issue is already being exploited

## What we will not publish here

This repository will not host proof-of-concept exploits, credential dumps, or detailed breakouts of physical security mechanisms that would help an attacker bypass access control in the field.

## Scope note

Public documentation mistakes (wrong principle, unclear wording) can be discussed in ordinary issues. Security-sensitive findings must stay private until maintainers assess impact.
